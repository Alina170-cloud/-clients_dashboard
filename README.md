# Динамика и доступность клиентской базы

Прототип дашборда для CRM-маркетинга: размер и доступность клиентской базы, воронка доступности, ёмкость и интенсивность коммуникаций по каналам (SMS, Email, Push).

> Все цифры — **сгенерированные демо-данные**, они не относятся к реальной базе.

## Запуск

Страница загружает данные из `data/*.json`, поэтому её нужно открыть через локальный сервер, а не двойным кликом по файлу:

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

d3 v7.9.0 подключается с cdnjs.

## Что на странице

- **Ключевые показатели** — вся база, доступная база, клиенты в целевых группах, неутилизированная база, индекс утилизации; изменение к предыдущему периоду.
- **Ёмкость по каналам** — распределение базы по сочетаниям доступных каналов и причинам недоступности.
- **Воронка доступности** — от всех клиентов до доставленной коммуникации, сравнение с предыдущим периодом, разрез «Все / Новые за период / Существующие», сегментатор по клику на шаг.
- **Воронка по каналам** — доля от всей базы на каждом шаге по каналам.
- **Динамика по неделям** — 52 недели, переключаемые области.
- **Распределение коммуникаций на клиента** — гистограмма с разбивкой по каналам по клику, использование допустимого объёма.
- **Детализированные данные** — таблица по каналам.

Фильтры: период (4 / 12 / 26 недель) и канал. У каждого блока есть подсказка «i» с описанием расчёта.

## Комментарии коллег

На странице подключён [Hypothesis](https://web.hypothes.is/): справа есть свёрнутая панель.

- **Оставить комментарий к месту:** выделить текст или число → «Annotate» → написать.
- **Общий комментарий к странице:** открыть панель → «Page Notes».
- **Важно:** при публикации выберите группу **Public**, иначе комментарий увидит только автор («Only Me»).
- Для комментирования нужен бесплатный аккаунт Hypothesis; читать можно без него.

## Структура

```
index.html                       страница дашборда
data/*.json                      демо-данные
scripts/generate_demo_data.py    генератор демо-данных (numpy)
```

Пересоздать данные: `python3 scripts/generate_demo_data.py` из корня репозитория (нужен numpy, около 2 ГБ памяти).

Лимиты контактной политики в демо условные: SMS — 1, Email — 2, Push — 3 сообщения в неделю, не больше 4 суммарно.
